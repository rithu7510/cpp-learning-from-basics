# Student Marks Analyzer

## About the Project
Student Marks Analyzer is a simple C++ console-based mini project that analyzes student marks and generates a performance report.

## Features
- Accepts marks for 1–100 students.
- Validates marks between 0 and 100.
- Calculates total marks and average.
- Finds highest and lowest marks.
- Counts passed and failed students.
- Allows users to repeat the analysis.

## Concepts Used
- C++ Functions
- Arrays
- For Loops
- While Loops
- Do-While Loops
- If-Else Statements

## Passing Criteria
- 40 and above: PASS
- Below 40: FAIL

## How to Run

Compile:
```bash
g++ StudentMarkAnalyzer.cpp -o analyzer.exe
```

Run on Windows:
```bash
.\analyzer.exe
```
